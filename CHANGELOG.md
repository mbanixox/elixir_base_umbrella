### Added

- Code quality is now automatically enforced — bad formatting or style issues are caught before code is committed
- A full automated test pipeline runs on GitHub every time code is pushed to ensure nothing is broken before it can be merged
- Security vulnerabilities in the web layer are automatically scanned on every push
- Security vulnerabilities in dependencies are automatically scanned on every push
